# Estimathon Scanner

Hey! I want to build a website for hosting jane street style estimathons. the idea is that contestants submit their answers using slips of papers with number written on them for their team number, the number of the problem they are submitting, and the upper and lower bound to the answer. I want to scan it with my phone, and have this update the scoreboard that i have up on my computer screen
